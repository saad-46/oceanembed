# GAHAN frontend

Next.js (App Router) + TypeScript + Tailwind + MapLibre GL + deck.gl + Recharts. Spec: `../docs/12_UI_UX_SPECIFICATION.md`.

```bash
npm install
cp .env.example .env.local      # NEXT_PUBLIC_API_URL (default http://localhost:8100)
npm run dev                     # http://localhost:3100
npm run build && npm start      # production
npm run lint && npm run typecheck
```

- Deploying to Vercel (Root Directory `frontend`, env `NEXT_PUBLIC_API_URL` = deployed backend URL): see
  `../docs/VERCEL_DEPLOYMENT.md`. `localhost:8100` is the `npm run dev` default only; a production build never uses it.

- Basemap is fully offline: clipped Natural Earth GeoJSON in `public/geo/` (no tile CDN).
- If the API is unreachable, `lib/api.ts` falls back to bundled snapshots in `public/fallback/`
  (generated by `../scripts/snapshot_fallback.py`) and labels the view "Offline fallback".
- Screens: `/` landing · `/map` ocean map + profile drawer · `/analysis` region stats + Cyclone Fuel Gauge ·
  `/validation` · `/insights` embedding + importance + assistant · `/reports` · `/methodology`.
